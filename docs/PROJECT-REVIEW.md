# بررسی TaskOS

تاریخ: ۱۲ سپتامبر ۲۰۲۶
هدف: یک دور ببینیم چه چیز هست، چه چیز کم است، و کجا می‌توان بهترش کرد.

TaskOS میز کار شخصی یک نفر است برای تمرکز روزانه، هم‌راه‌شدن با جیرای SmartX، و ثبت زمان روی تیکت.
یک کاربر است (رضا)، محلی، بدون لاگین، روی ویندوز + کروم.

---

## یک نگاه به معماری

| قطعه | فناوری | نکته |
|---|---|---|
| API | ASP.NET 9، SQLite | `http://127.0.0.1:5088` — `backend/TaskOS.Api` |
| UI | React + Vite + Tailwind | `http://127.0.0.1:5173` — پراکسی `/api` و `/jira-rest` |
| اکستنشن کروم | MV3 unpacked | نسخه فعلی ۰.۶.۹ — بعد تغییر JS باید Reload شود |
| جیرا | Server/DC `jira.smartx.ir` | پروژه‌ها: **PS** پشتیبانی، **SIP** ساختن، **IO** فقط مشاهده |
| اجرا | `start-taskos.bat` / `start-on-boot.bat` | هلث HTTP؛ اگر listen-بامرده باشد کشته می‌شود |

توکن جیرا در `appsettings.Local.json` است (جیت‌اگنور).

## قوانین ثابت محصول (عمداً نشکن)

1. تسک خودکار ورودی فقط از **PS**. SIP/IO تسک نمی‌سازند.
2. ساختن تیکت از QuickAdd فقط **SIP**.
3. حذف تسک TaskOS وضعیت جیرا را عوض نمی‌کند.
4. ورک‌لاگ مرتبط به تیکت می‌رود جیرا؛ بدون comment.
5. تیکت PS رجیسترشده فقط اگر **بدون تحویل‌گیر** به رضا تخصیص می‌گیرد.
6. واژه کاربر: **تیکت** نه تکت.
7. باز کردن تیکت زیر ۳۰ ثانیه = فقط نگاه. فوکوس TaskOS عوض نمی‌شود.
8. Done جیرا → Done تسک. Done تسک → جیرا عوض نمی‌شود و باز هم باز نمی‌شود.
9. مالکیت: من / نام تحویل‌گیر (یا «دیگری»).
10. پاپ‌آپ «چیکار می‌کنی؟» وقتی سیستم Pause است نمی‌آید.
11. دلیل Stuck فقط: منتظر کسی‌ام / یادم رفت / سخته / مهم نیست دیگه.
12. زمان تا خروج از تسک جمع می‌شود؛ تیک خودکار ۵ دقیقه قطع است.

## چه چیز الان وجود دارد

### ۱) کارهای امروز (هسته محصول)

- لیست تسک‌ها، Deep / Light، فیلتر وضعیت / تیکت / مالکیت / انرژی
- نمای استاندارد و زن
- افزودن سریع (محلی یا ساختن SIP)
- تشابه عنوان با تسک‌های قبلی
- کشوی ویرایش + صفحه جزئیات
- چک‌لیست مراحل، برچسب، پین
- مالکیت من / دیگری با نام تحویل‌گیر جیرا
- روزهای قبل + rollover پایان روز
- سطل زباله (برگرداندن / حذف دائم)

### ۲) تمرکز و زمان

- یک تسک فعال (بنر «الان دارم کار می‌کنم»)
- ورک‌لاگ روی تسک / مسئله + ارسال به جیرا
- پاپ‌آپ ویندوز «چیکار می‌کنی؟» با فاصله قابل تنظیم
- پاپ‌آپ وب + اکستنشن کروم (جیرا + idle)
- گزارش امروز: جمع زمان روی هر تسک + پراکندگی پرش
- ثبت دستی زمان روی خود تسک

### ۳) جیرا

- پول تیکت‌های PS بدون تحویل‌گیر → تخصیص به رضا + ساختن تسک
- نوتیف تسک جدید و کامنت جدید (توست تا کلیک)
- نخ کامنت محلی + جیرا روی تسک
- بسته شدن جیرا → فلاش زمان + Done تسک (پول ۵ ثانیه + اکستنشن)
- فرم توضیح پایان کار وقتی جیرا Done می‌شود

### ۴) استودیوی مسئله (ساخته، کم‌استفاده)

پنج پله: یک خط مسئله → قید برعکس → حداقل سه گزینه → توضیح جونیور → پیش‌مرگ و تأیید.
این بخش جدا از جریان اصلی روز (تیکت PS) جدا است.

### ۵) دفترچه یادگیری

یادداشت آزاد روز به تاریخ. به جیرا و تسک وصل نیست.

### ۶) تنظیمات

فاصله پینگ، پاز / ادامه هشدار، تست پاپ‌آپ ویندوز.

## سطح‌های UI حالا

| مسیر | نقش |
|---|---|
| `/` | کارهای امروز |
| `/tasks/:id` | جزئیات تسک (چک‌لیست، کامنت، زمان) |
| `/notifications` | تسک / کامنت جدید |
| `/reports` | زمان امروز + پراکندگی |
| `/problems` و `/problems/:id` | استودیوی مسئله |
| `/dailylogs` | دفترچه یادگیری |
| `/trash` | سطل زباله |
| `/settings` | پینگ و پاز |

`/worklogs` (ثبت کار و زمان) حذف شد. زمان همان‌جا می‌ماند که واقعاً می‌خوانی: روی تسک، در گزارش، و با تمرکز/پینگ.

## چه چیز کم است یا ناقص

### جریان اصلی (تیکت + تمرکز)

- ورک‌لاگ‌های قدیمی جیرا هنوز تکه‌تکه ۵ دقیقهاند؛ جمعشان درست است ولی شکل نیست.
- گزارش فقط «امروز» است. هفته / ماه / تیکت‌های بیشترین زمان ندارد.
- بعد حذف صفحه ورک‌لاگ: مرور روزهای قبل، کپی خلاصه برای جیرا، و دکمه‌های استراحت/ناهار جایی ندارند (اگر بخواهیشان باید بروند گزارش).
- پینگ ویندوز هنوز می‌تواند وقتی فوکوس فعال است مزاحم باشد.
- اکستنشن با Reload دستی به‌روز می‌شود؛ نسخه روی آیکون باید خودت ببینی.

### ناوبری و تکرار

- منو شلوغی است: کار / نوتیف / گزارش / مسئله / دفترچه / سطل / تنظیمات.
- کشو و صفحه جزئیات تقریباً یک کار را دو بار نشان می‌دهند.
- فیلترها روی دشبورد زیادند.

### مسئله و یادگیری

- استودیو به تیکت PS وصل نیست. برای یک تیکت سخت باید دستی مسئله جدا ساخت.
- دفترچه با رول‌اور پایان روز و گزارش هم‌پوش است.

### زیرساخت و قابلیت

- بدون لاگین و بدون پشتیبان آنلاین. برای یک نفر روی لپ‌تاپ قصدی است.
- SQLite فایل محلی؛ بکاپ رسمی ندارد.
- نسخه موبایل / ریسپانسیو ندارد.
- تست اتوماتیک و CI ندارد.
- README پایان فاز ۱ مانده (ورک‌لاگ ۱۵ دقیقه).

### طراحی‌شده ولی ساخته‌نشده (از `docs/DESIGN-SURFACES.md`)

- تمپلیت چک‌لیست
- وابستگی اجباری بین مراحل
- Query / File / Note روی هر مرحله
- Drag & Drop مراحل

این‌ها اولویت روزانه نیستند مگر چک‌لیست واقعاً روی تیکت‌های سخت استفاده شود.

## چه کاری می‌توان بهترش کند (به ترتیب اثر)

### اولویت بالا — همان جریان فعلی

1. **گزارش را جای صفحه ورک‌لاگ کن.** انتخاب روز، جمع هفته، لیست تیکت‌های پرزمان. اگر کپی برای جیرا هنوز لازم است، همین‌جا.
2. **آرامش فوکوس.** یک نگاه: چه کاری فعل است، چقدر زمان رویش جمع شده، پاز بدون ابهام.
3. **پینگ را کم‌سروصدا.** اگر همان کار فعال است، نپرس. فقط وقتی فوکوس نداری یا زمان طولانی شده.
4. **کامنت‌های جیرا.** پاسخ سریع از TaskOS خوب است؛ نشان دادن «منتظر پاسخ من» روی تیکت هنوز نیست.

### اولویت وسط — کم‌تر ولی مفید

5. **خرد کردن تیکت سخت.** از Stuck «سخته» یک چک‌لیست یا یک مسئله جدید شود.
6. **یکی کردن پایان روز.** rollover + دفترچه + گزارش در یک جریان.
7. **کم کردن منو.** سطل و تنظیمات زیر منوی دوم. مسئله اگر استفاده نمی‌شود هم همان‌جا.
8. **نشان دادن نسخه اکستنشن** در تنظیمات یا فوتر.

### اولویت پایین — فقط اگر درد کرد

9. بکاپ خودکار فایل SQLite (روزانه یا با شروع).
10. تم روشن / تطبیق با اندازه پنجره.
11. تمپلیت چک‌لیست و وابستگی مراحل.
12. موبایل یا PWA.

## پیشنهاد بررسی

هسته برای جریان واقعی کافی است: تیکت PS می‌آید، فوکوس می‌گیرد، زمان می‌رود جیرا، Done یک‌طرفه است.

جای خالی در «قسمت جدید» نیست. جای خالی این است:

- گزارش را جای صفحه‌ای بگذاری که حذف شد
- فوکوس را قابل اعتماد کن
- منو را کوتاه کن
- استودیو را به تیکت وصل کن یا اگر استفاده نمی‌شود کنار بگذار

اگر بعد از خواندن این فایل یک خط را انتخاب کنی، همان را اجرا می‌کنیم.
